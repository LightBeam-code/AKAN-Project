# AKAN-Name Generator

## Description
This is a website that geneates a an 'AKAN' name for a user when he/she fills in his/her information using a form.
AKAN names are names given to children based on the day of the week the children were born and the order in which parent's children were born.
The website contains amazing backgounds and an interactive page used to collect information from the user.
It also contains a brief description on AKAN names and their matches to both men and women.
